# Security policy

## Supported versions

Security fixes target the latest `main` branch. Update to the latest release or
commit before checking whether an issue still applies.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Khaled2049/taleTribe-recs/security/advisories/new)
to contact @Khaled2049 privately. Do not open a public issue for an undisclosed
vulnerability or include credentials or personal data in a report.

Include the affected commit, impact, reproduction steps, and a minimal example.
Repository code, dependencies, workflows, and deployment configuration are in
scope. Test only systems and accounts you own or have permission to test; do not
access other users' data or disrupt production. No response-time or bounty is
promised. Coordinate disclosure with the maintainer after a fix is available.
